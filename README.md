# Comarca Validation

Plataforma científica para la validación observación-modelo en la
Comarca Andina.

El proyecto integra observaciones de calidad del aire y meteorología
con resultados de modelos atmosféricos para evaluar y visualizar
el desempeño del sistema de modelado.

## Objetivos

- Integrar observaciones de calidad del aire.
- Integrar observaciones meteorológicas.
- Comparar observaciones con CALMET y CALPUFF.
- Visualizar series temporales observación-modelo.
- Conservar distintas corridas del modelo para su evaluación.
- Facilitar el análisis científico y la validación del sistema.
